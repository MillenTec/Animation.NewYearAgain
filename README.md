## 1.简述
在中国农历中每年的第一天，是中国的春节，一个对于中国人来说意义非凡的节日，每到这一天，人们都会设法与家人团聚；2026年的春节正是2月17日

我制作了这个动画以迎接春节的到来，动画中大致描绘了一位中国人在春节这一天会经历的一些事情，比如购置年货、回家团圆、吃年夜饭等等

这个动画制作得有些仓促，在2月15日晚上才刚刚从Ae中渲染出来，所以目前有很多地方做得不足，特别是后半段可以看见质量相比前半段有较明显的下降，非常抱歉

在此仓库中的版本移除了大部分第三方素材资源，故若工程文件中出现脱机素材请忽视

> 对于.prproj文件中的视频主轨道，你应该自行在Ae中渲染出来并替换
